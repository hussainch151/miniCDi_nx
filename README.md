# miniCDi_nx
miniCDi is originally made by CatmanFan all credit goes to him for making this emulator link: https://github.com/CatmanFan/miniCDi

miniCDi_nx is a port of miniCDi Emulator for Nintendo Switch

# Usage

Place the minicdi.nro in /switch/minicdi/ for the bios its /minicdi/rom/ and then for your cdi game dumps its /minicdi/discs/


# Controls

|                      |                  |
|----------------------|------------------|
| Button 1             | A                |
| Button 2             | B                |
| Directional buttons  | Left stick/D-Pad |
| *Reset emulator*     | L                |
| *Play button on FP*  | +                |
| *Open GUI*           | R                |

expect many bugs like *controls not working correctly* and *audio not working correctly* as the emulator is still expermental
