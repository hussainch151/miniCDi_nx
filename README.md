# miniCDi_nx
miniCDi is originally made by CatmanFan all credit goes to him for making this emulator

miniCDi_nx is a port of miniCDi Emulator for Nintendo Switch

*Controls*

|                      |                  |
|----------------------|------------------|
| Button 1             | A                |
| Button 2             | B                |
| Directional buttons  | Left stick/D-Pad |
| *Reset emulator*     | L                |
| *Play button on FP*  | +                |
| *Open GUI*           | R                |
